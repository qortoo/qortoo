The guides explain how to use Qortoo. API documentation describes the public types and methods.

## Rust

Generate the Rust API documentation from your `qortoo-rs` checkout:

```sh
cargo doc --no-deps -p qortoo --open
```

Cargo writes the generated reference to `target/doc/`. For a first example, follow [Getting Started](/docs/rust/getting-started/).

[Browse the Rust public API source](https://github.com/qortoo/qortoo-rs/blob/main/src/lib.rs).

## Go

Use `go doc` from your `qortoo-go` checkout to inspect the package documentation:

```sh
go doc github.com/qortoo/qortoo-go
```

[Browse the Go SDK source](https://github.com/qortoo/qortoo-go) or follow [Getting Started](/docs/go/getting-started/).

Hosted API references are not available on this site yet.
