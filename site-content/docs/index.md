Qortoo provides conflict-free replicated datatypes, local atomic transactions, and synchronization through pluggable connectivity. Choose your SDK to get started.

## Choose your SDK

- [Rust getting started](/docs/rust/getting-started/) — use the core implementation directly.
- [Go getting started](/docs/go/getting-started/) — use the Go API backed by the Rust core.

Qortoo is a pre-release project. The bundled backends operate in-process; server components are planned and are not yet available.

## Understand the model

Start with [Architecture](/docs/rust/architecture/), then explore [Counter](/docs/rust/counter/), [Variable](/docs/rust/variable/), and [Transaction and Rollback](/docs/rust/transaction-and-rollback/).

Shared core concepts live in the Rust SDK documentation. Go-specific behavior is covered in [Lifecycle and Concurrency](/docs/go/lifecycle-and-concurrency/).
