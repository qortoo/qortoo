# Developer

Shared development guides for the Qortoo repositories. These Markdown sources
live in `qortoo/docs/` and are published here from the same website revision.

- [Repository workflows](repository-workflows.md): repository roles, CI, and publication.
- [Developer site](developer-site.md): local website setup, content, and validation.
- [Benchmark display](benchmark-results.md): how official results appear on the website.

SDK behavior belongs in each SDK's guides; benchmark operations belong to
[Qortoo Bench](https://github.com/qortoo/qortoo-bench/blob/main/docs/performance.md).
